# Stela

Настольный конфигуратор памятников. Собирает участок из импортированных 3D-моделей, задаёт габариты **в сантиметрах** и наносит на стелу **гравировку** и **фотокерамику** — на лицевую или обратную сторону.

Stela не лепит форму памятника кистью. Геометрия приходит из Blender (OBJ, glTF, GLB) либо показывается габаритной заглушкой, пока модель не импортирована. Сцена собирается заново при каждом изменении проекта: масштаб под заказ, обрезка по земле, врезка текста и объёмные медальоны.

Интерфейс на русском. В бинарник вшит DejaVu Sans, поэтому кириллица и типографские знаки рисуются и на Windows без отдельной установки шрифта.

Лицензия: [MIT](LICENSE).

## Возможности

- Несколько памятников на одном участке. У каждого своя тумба, стела и остальные детали.
- Роли деталей: стела, тумба, ограда, цветник, стол, лавка, крест, надгробие, прочее. Библиотека моделей фильтруется по роли.
- Импорт в деталь: из файла или из библиотеки. Пока файла нет, на участке стоит заглушка точного размера.
- Размеры в сантиметрах (ширина × высота × глубина). Модель масштабируется неравномерно под эти габариты, низ садится на заданную высоту.
- Смещение ΔX / ΔY / ΔZ. Отрицательный ΔY опускает деталь в землю; всё ниже плоскости Y = 0 отрезается.
- Стела и крест с включённой автоукладкой встают на верх тумбы той же группы.
- Текстуры гранита, мрамора и других камней — отдельные библиотеки. Накладываются на деталь и на покрытие участка. Развёртка — box UV с шагом 0,5 м, боковые грани не растягиваются в одну полосу.
- Эскизы на стеле слоями, как в редакторе: имя, видимость, сторона, положение на лице.
- Текст — трёхмерная гравировка. Контур шрифта вычитается из камня на глубину около 3,5 мм (регулируется). Отверстия букв (6, Ф, б, О) остаются камнем. Дно и стенки одного цвета.
- Фотокерамика — объёмная пластина, а не картинка поверх экрана. Форма, материал, стандартный размер, крепление, вырез портрета по цвету краёв, фон из библиотеки этой формы, подпись на пластине.
- Стартовый экран: название участка, новый проект, карточки сохранённых работ, переход в библиотеку.

## Требования

- [Rust](https://rustup.rs/) stable (в репозитории зафиксирован `stable` в `rust-toolchain.toml`)
- Для окна нужен графический сеанс

### Linux

```bash
sudo apt install -y build-essential pkg-config \
  libxkbcommon-x11-0 libgl1 libegl1 fonts-dejavu-core
```

`fonts-dejavu-core` нужен как запасной шрифт гравировки, если в библиотеку ещё ничего не импортировано. Интерфейс использует вшитый DejaVu и без этого пакета.

### Windows

1. Установите [rustup](https://rustup.rs/).
2. Установите Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» (линковщик `link.exe`).
3. Распакуйте исходники и соберите проект командой ниже.

Готовый набор исходников для Windows лежит в `stela-windows.zip` (Cargo-манифест, lockfile, тулчейн, `src/`, `assets/`, этот README). Каталог `target/` в архив не входит.

## Сборка и запуск

```bash
cargo run --release
```

Отладочная сборка быстрее компилируется и удобна при правках:

```bash
cargo run
cargo test
```

Бинарник релизной сборки: `target/release/stela` (на Windows — `target\release\stela.exe`).

Релизная сборка включает LTO и один codegen-unit: компиляция дольше, бинарник меньше и быстрее в окне.

## Как работать

1. На стартовом экране введите имя и нажмите **Новый проект…**. Файл `.stela.json` выбирается в диалоге, как при сохранении в обычном редакторе.
2. Слева — памятники и детали. Кнопки добавляют стелу, тумбу, ограду и остальные роли. Участок по умолчанию 180×200 см; пресеты и свои сантиметры задаются в панели участка.
3. Справа у выбранной детали: размеры в см, смещения, поворот, импорт модели, текстура. У стелы — слои эскиза.
4. **+ Эскиз текста…** открывает редактор гравировки. **Фотокерамика…** открывает редактор медальона. У слоя выбирается сторона: лицевая или обратная.
5. **Библиотека** — вкладки «Модели», «Текстуры», «Шрифты», «Фоны».
6. Во вьюпорте левая кнопка мыши вращает камеру, колесо приближает. Счётчик `нарисовано/всего граней` показывает, какая часть модели попала в кадр: если числа близки, сетка загружена целиком.

Новый проект сразу содержит тумбу и стелу. Стела стоит на тумбе.

## Гравировка

Редактор текста задаёт:

- строки (фамилия, даты — обычный многострочный текст);
- шрифт из библиотеки (TTF/OTF) либо системный запасной;
- высоту заглавной в сантиметрах, жирный и курсив, выравнивание, межстрочный интервал;
- цвет дна и стенок;
- глубину в миллиметрах (по умолчанию 3,5 мм);
- сторону стелы и положение слоя на лице.

Контуры глифов собираются в многоугольник с дырками, триангулируются и вырезаются из передней поверхности. В полость кладётся сплошное дно и стенки. После врезки каменная текстура заново раскладывается по ящику, так что гравировка не срывает рисунок с остальной стелы.

## Фотокерамика

Медальон — отдельная трёхмерная пластина на поверхности стелы. Размер берётся из сантиметров заказа, а не из доли экрана.

Портрет вырезается заливкой от краёв изображения: пиксели, близкие к цвету рамки, становятся прозрачными. Это не нейросеть. Допуск настраивается. Если фон снимка пёстрый и не совпадает с краями, снимите флажок «Вырезать фон по цвету краёв» и оставьте фото как есть. Готовое лицо (портрет, фон формы, подпись) кэшируется в `library/cache/`.

Портрет, врезанный в камень гравировкой, в этой версии не делается.

Жёлтой рамки выделения вокруг фото нет: пластина видна в самой сцене.

### Материалы

| Материал | Толщина пластины | Крепление |
|---|---|---|
| Керамогранит | 10 мм | в нишу на клей (по умолчанию) или на поверхность на клей |
| Фарфор | 6 мм | в нишу на клей (по умолчанию) или на поверхность на клей |
| Металлокерамика | 1,5 мм | только саморезы с герметизацией, четыре шляпки |

Ниша вырезается в камне на толщину пластины: лицевая сторона медальона заподлицо со стелой, на дне ниши тёмная площадка. Клей на поверхность и саморезы ставят пластину поверх камня, без ниши. Саморезы для керамогранита и фарфора недоступны. Ниша и поверхностный клей недоступны для металлокерамики.

### Формы и стандартные размеры

Ширина × высота, сантиметры.

| Форма | Керамогранит | Фарфор | Металлокерамика |
|---|---|---|---|
| Овал | 13×18, 18×24, 20×30, 30×40 | 9×12, 13×18, 18×24 | 13×18, 18×24, 17×22 |
| Прямоугольник | 13×18, 18×24, 20×30, 30×40 | 9×12, 13×18, 18×24 | 13×18, 18×24, 17×22 |
| Арка | 13×18, 18×24 | — | — |
| Бочка | — | — | 13×18, 17×22 |

Прямоугольник слегка скруглён (около 3 мм). Бочка — прямоугольник с выпуклыми сторонами. Арка — прямоугольник с полукруглым верхом.

Фоны хранятся отдельно для каждой формы: овал не предлагает фон арки. Подпись (ФИО, даты) рисуется на пластине: шрифт, кегль, цвет, выравнивание.

## Библиотека и файлы

Каталог данных приложения — `dirs::data_dir()/stela`:

| ОС | Каталог |
|---|---|
| Linux | `~/.local/share/stela/` |
| Windows | `%APPDATA%\stela\` |
| macOS | `~/Library/Application Support/stela/` |

| Что | Файл или папка |
|---|---|
| Список проектов | `atelier.json` |
| Сам проект | путь, выбранный в диалоге (`.stela.json`) |
| Каталог библиотеки | `library/catalog.json` |
| Модели | `library/models/`, превью в `library/previews/` |
| Текстуры | `library/textures/`, превью в `library/texture_previews/` |
| Шрифты | `library/fonts/` |
| Фоны медальонов | `library/backgrounds/`, превью в `library/background_previews/` |
| Кэш лиц медальонов | `library/cache/` |

При первом запуске, если библиотека шрифтов пуста, программа копирует туда найденные системные DejaVu или Liberation.

Файл проекта — JSON (serde). В нём участок, памятники, детали, пути к моделям и текстурам, слои эскизов. Пути абсолютные: перенос на другой компьютер требует тех же файлов или повторного импорта.

## Экспорт из Blender

Предпочтительно **File → Export → glTF 2.0** (`.glb`, можно и `.gltf`). Также читается Wavefront (`.obj`, Y-up).

Единицы и габариты в Blender могут быть любыми. Stela вписывает сетку в введённые сантиметры: низ на опорную плоскость детали, центр по XZ. Нормали пересчитываются после неравномерного масштаба. Тонкие ограды и панели рисуются с двух сторон.

Имеет смысл экспортировать каждую роль отдельно (стела, тумба, секция ограды), а не весь комплекс одним файлом: размеры и текстуры задаются подетально.

## Стек

Rust 2021, [egui / eframe 0.29](https://github.com/emilk/egui), glam, serde. Модели: `tobj`, `gltf`. Картинки: `image` (PNG, JPEG, WebP). Шрифты гравировки и подписи: `ttf-parser`, `ab_glyph`. Вырезка букв и ниши: `geo`, `earcutr`. Окно выбора файлов: `rfd`.

Вьюпорт — программный Z-буфер с сглаживанием 2×2, без GPU-шейдеров. Поэтому проект собирается там, где собирается egui, и не зависит от конкретного OpenGL-профиля видеокарты сверх того, что нужно самому egui.

## Ограничения

- Форма памятника не моделируется внутри программы. Нет кисти, булевых операций по произвольной сетке и экспорта обратно в Blender.
- Вырез фона портрета — заливка от краёв по близости цвета. Сложный фон (листва, комната, градиент) она не отделяет.
- Портрет гравировкой по камню не реализован.
- Гравировка и медальон строятся по габаритному лицу стелы (прямоугольник ширины и высоты детали), а не по силуэту импортированной сетки. Фигурный верх стелы текст не обтекает.
- Текстуры — альбедо без нормалей и нескольких UV-каналов из файла.
- Это инструмент компоновки заказа, не фотореалистичный рендер.
